🧮 Math Challenge Game
🌟 Project Overview
Math Challenge is an interactive, browser-based quiz game designed to test and improve basic arithmetic skills. Built using JavaScript, this project showcases dynamic DOM manipulation, timer logic, and game state management.

🎮 How to Play
The game generates random math problems (Addition/Subtraction).

You have 3 Lives (❤️❤️❤️). Every wrong answer costs you one life.

You must score 10 points to win the game.

There is a 60-second timer. Try to finish as fast as you can to get the "Excellent" rank!

🛠️ Tech Stack
HTML5: For the game structure and layout.

CSS3: For the dark-themed UI and responsive design.

JavaScript (ES6): For game logic, random number generation, and event handling.

✨ Key Features
Dynamic Scoring: Real-time score updates.

Health System: Visual feedback using heart emojis for lives.

Performance Ranking: After winning, the game ranks you as "Excellent", "Best", or "Good" based on your time.

Dark UI: A modern, eye-friendly interface.
